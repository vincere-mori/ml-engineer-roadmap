## 🎯 Стратегия для студента / начинающего

### Что играет в плюс
- 🎓 Топовый технический вуз (ИТМО / МФТИ / ВШЭ / МГУ / Сколтех) — учитывается рекрутерами
- 📐 Сильный математический фундамент → быстрее заходят DL и теория
- 🗄️ Если умеешь в Data Engineering, это **редкое** сочетание для джуна и заметный плюс в резюме
- 💪 Время до выпуска — возможность пройти стажировку

### Конкретный план на 12 месяцев
1. **Сейчас → +3 мес**: добить математику + classical ML + первое Kaggle
2. **+3 → +6 мес**: DL + 1 сильный pet-проект → подаваться на **стажировки**
3. **+6 → +9 мес**: стажировка + LLM/RAG + MLOps
4. **+9 → +12 мес**: получить **оффер** (мидл-джун или мидл) и/или поступить в **ШАД**

## 📝 Резюме (что важно для РФ)

- 1 страница, без воды
- **Стек технологий** — отдельным блоком сверху
- Проекты с **метриками**: «увеличил precision с 0.72 до 0.81», «ускорил inference в 3.2× через ONNX»
- GitHub профиль с **закреплёнными** проектами
- Без фото на хабр-карьеру / getmatch (на hh — можно)

### Структура
1. Контакты + Telegram + GitHub
2. О себе (3–4 строки)
3. Навыки (стек)
4. Опыт / проекты
5. Образование
6. Дополнительно: соревнования, статьи, сертификаты

## 💸 Как торговаться

- На джуне торг небольшой, но **±15–20%** реален
- Уточни **грейдинговую сетку** компании
- Сравни 2–3 оффера **параллельно** (даже если основной нравится)
- **Не называй** свою текущую/желаемую цифру первым (на ранних этапах)
- Считай **total comp**: оклад + премии + опционы (Yandex/Sber дают RSU-аналоги)
