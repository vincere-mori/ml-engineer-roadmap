## 🎲 Теория вероятностей и статистика

> **Самая важная часть** для ML интервью.

- [ ] Вероятностные пространства, условная вероятность, Байес
- [ ] Случайные величины, распределения (норм, Бернулли, Пуассон, экспон)
- [ ] Мат.ожидание, дисперсия, ковариация, корреляция
- [ ] ЦПТ, ЗБЧ
- [ ] Точечные и интервальные оценки, ММП (MLE), MAP
- [ ] Проверка гипотез: t-test, χ², Манна-Уитни
- [ ] A/B тесты: дизайн, мощность, MDE, бутстрэп
- [ ] Causal inference (introduction)

📚 **Ресурсы:**
- [Курс Х. Карпова — A/B тесты](https://karpov.courses/simulator-ab) — золотой стандарт
- [ШАД — Теорвер и статистика](https://education.yandex.ru/handbook/ml)
- Wasserman «All of Statistics»
- [Stepik — Основы статистики (Анатолий Карпов)](https://stepik.org/course/76)
